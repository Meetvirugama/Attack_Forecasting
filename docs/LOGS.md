# Logs Directory

This directory stores all runtime log files generated by the system.

---

## Log Files

| Log File | Generated By | Description |
|:---|:---|:---|
| `world_model_training.log` | `train.py` | Full training pipeline output — epoch losses, validation accuracy, benchmark results |
| `api_server.log` | `app/api.py` | REST API server request handling and model inference events |
| `preprocessing.log` | `src/state_aggregator.py` | State aggregation and feature engineering output |
| `explainability.log` | `src/temporal_explainer.py` | XAI saliency and attention attribution events |

---

## Log Format

All logs use the format defined in `app/config.py`:

```
%(asctime)s — %(name)s — %(levelname)s — %(message)s
```

Example:
```
2026-09-28 23:45:12 — TrainPipeline — INFO — Extracted 18,430 autoregressive sequences (10 timesteps × 30 features)
2026-09-28 23:45:15 — TrainPipeline — INFO — Epoch 01/08 | Train Loss: 0.4821 | Val Acc: 87.34%
2026-09-28 23:48:02 — NIDS-API — INFO — World Model loaded successfully.
2026-09-28 23:48:03 — NIDS-API — INFO — MITRE Attack Chain Predictor loaded.
```

---

## Controlling Log Level

Set the `LOG_LEVEL` environment variable (in `.env` or shell) before launching:

```bash
LOG_LEVEL=DEBUG python run_server.py   # verbose output
LOG_LEVEL=WARNING python run_server.py # warnings and errors only
```

Supported levels: `DEBUG`, `INFO`, `WARNING`, `ERROR`.

---

## Notes

- Log files (`*.log`) are **excluded from git** via `.gitignore`
- The `logs/` directory is auto-created by `train.py` and `app/api.py` on first run
- Rotate or clear logs manually if they grow large during long training runs
